# Zona Strings

Website for Echezona Ogudu (Zona Strings): hand-cut Ankara fabric portraits.

Built with Next.js 16 (App Router), Tailwind CSS 4 and GSAP.

```bash
npm install
npm run dev
```

## Editing content

Text, works, services, process steps and stats are in `data/site.js`.
Images are in `public/work/`, video loops in `public/video/`.
To add a piece, drop the image in `public/work/` and add an entry to `works`.
The first four works appear in the home page's "Recent work" stack.
